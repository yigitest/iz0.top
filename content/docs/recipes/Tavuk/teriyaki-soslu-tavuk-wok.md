# Wok Tavasında Teriyaki Soslu Tavuk

> [!NOTE]
> **Tarif Özeti**  
> Soya sosu, pirinç sirkesi, akçaağaç şurubu, sarımsak ve zencefil marinesiyle hazırlanan, wok tavada yüksek ateşte hızlıca pişirilen lezzetli bir tavuk yemeği.

## Malzemeler

| Malzeme | Miktar | Notlar |
| :--- | :--- | :--- |
| Tavuk | - | |
| Soya sosu | 1/4 su bardağı | |
| Pirinç sirkesi | 1/4 su bardağı | |
| Akçaağaç şurubu (Maple syrup) | 1 yemek kaşığı | |
| Zencefil | - | |
| Sarımsak | 4–5 diş | |
| Karabiber | - | |
| Tuz | - | |

## Hazırlanışı

{{% steps %}}
1. ## Tavuğu marine edin
   Kapaklı bir kaba tavuk, soya sosu, pirinç sirkesi, akçaağaç şurubu, zencefil, sarımsak, karabiber ve tuzu ekleyin. Tüm malzemeler tavukla iyice bütünleşene kadar elinizle karıştırın.

2. ## Dinlendirin ve yüksek ateşte pişirin
   Marine edilen tavuğu tercihen kapağı kapalı şekilde buzdolabında bir gece bekletin. Pişirme aşamasında wok tavayı kızdırın ve tavukları yüksek ateşte soteleyerek kızartın.
{{% /steps %}}

## Notlar

> [!TIP]
> **Marine İpucu**  
> Tavukların sosu iyice emmesi ve yumuşaması için buzdolabında 1 gece marine edilmesi lezzeti önemli ölçüde artırır.
