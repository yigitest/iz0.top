# Sıcak Şarap (Mulled Wine)

> [!NOTE]
> **Tarif Özeti**  
> Portakal, limon kabuğu ve aromatik baharatların kırmızı şarapla kısık ateşte demlenmesiyle hazırlanan, geleneksel ve iç ısıtan bir sıcak kokteyl tarifi.

## Malzemeler

| Malzeme | Miktar | Notlar |
| :--- | :--- | :--- |
| Portakal | 2 adet | 1 adedinin kabuğu soyulmuş, 2 adedinin suyu sıkılmış |
| Limon | 1 adet | Sadece kabuğu |
| Pudra şekeri | 150 g | |
| Karanfil | 5 adet | |
| Kakule tohumu | 5 adet | Ezilmiş |
| Çubuk tarçın | 1 adet | |
| Muskat | 1 tutam | Rendelenmiş |
| Kırmızı şarap | 2 şişe | |
| Zencefil şarabı (Ginger wine) | 150 ml | İsteğe bağlı (nota bakınız) |

## Hazırlanışı

{{% steps %}}
1. ## Şerbet tabanını hazırlayın
   Tencereye 1 portakalın kabuğunu, 2 portakalın suyunu, limonun kabuğunu, pudra şekerini ve baharatları (karanfil, ezilmiş kakule tohumu, çubuk tarçın ve muskat) ekleyin. Üzerlerini örtecek kadar az miktarda şarap dökün.

2. ## Aromaları yoğunlaştırın
   Şeker eriyene kadar orta ateşte ara ara karıştırarak pişirin. Karışım kaynamaya başladıktan sonra aromaların özleşmesi için 5–8 dakika daha pişirmeye devam edin.

3. ## Şarabın kalanını ekleyin ve ısıtın
   Ocağın altını kısın ve şarabın kalanını tencereye ekleyin. İstenen servis sıcaklığına gelene kadar ısıtın (şarabın kaynamamasına dikkat edin).
{{% /steps %}}

## Notlar

> [!NOTE]
> **Zencefil Şarabı (Ginger Wine)**  
> Orijinal tarifte geçen 150 ml zencefil şarabı elinizde yoksa eklenmeden de hazırlanabilir.
