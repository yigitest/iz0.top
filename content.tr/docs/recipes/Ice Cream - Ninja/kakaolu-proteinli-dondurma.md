# Kakaolu Proteinli Dondurma

> [!NOTE]
> **Tarif Özeti**  
> Tam yağlı süt, badem sütü, vanilyalı whey protein ve kakao ile hazırlanan 2 haznelik proteinli kakaolu dondurma tarifi.  
> *Besin Değerleri: Toplam 575–585 kcal (hazne başına ~290 kcal).*

## Malzemeler

| Malzeme | Miktar | Notlar |
| :--- | :--- | :--- |
| Tam yağlı süt | 300 ml | - |
| Şekersiz badem sütü | 300 ml | - |
| Vanilyalı whey protein tozu | 54 g | - |
| Kakao tozu | 25 g | - |
| Şeker | 20–22 g | - |
| Kıvam arttırıcı (gum) | Az miktarda | Ksantan gam vb. |
| Tuz | 1 tutam | - |

## Hazırlanışı

{{% steps %}}
1. ## Karışımı Hazırlayın
   Tam yağlı süt, şekersiz badem sütü, vanilyalı whey protein tozu, kakao tozu, şeker, kıvam arttırıcı ve tuzu pürüzsüz bir kıvam alana kadar blender veya çırpıcı ile karıştırın.

2. ## Haznelere Paylaştırın ve Dondurun
   Karışımı 2 dondurma haznesine (tub) eşit şekilde bölüştürün. Kapaklarını kapatarak dondurucuda donana kadar bekletin.

3. ## Ninja Creami'de Çekin
   Dondurulmuş hazneyi Ninja Creami cihazına yerleştirip dondurma modunda çalıştırarak servis edin.
{{% /steps %}}
